# Estructuras de Datos & Algoritmos — Java

Colección de implementaciones desarrolladas durante los cursos de
**Algoritmos y Estructuras de Datos I, II y III** en la
Facultad Politécnica — Universidad Nacional de Asunción (FPUNA).

## Contenido

### Árboles
- Árbol Binario de Búsqueda (BST) — versión tipada y genérica
- Medición de tiempos de inserción y búsqueda en BST

### Listas Enlazadas
- Lista simplemente enlazada
- Lista doblemente enlazada
- Implementación desde cero de las listas de Python en Java

### Algoritmos de Ordenación
- QuickSort (versión simple y con criterio personalizable)
- RadixSort para cadenas alfanuméricas
- Mezcla (Merge)

### Grafos
- Implementación de ejercicios con grafos usando JGraphT
- Detección de ciclos
- Algoritmos de recorrido

### POO & Patrones
- Herencia, interfaces y clases abstractas
- Jerarquías de empleados, vehículos y figuras
- Manejo de excepciones

## Tecnologías
- Java (JDK 11+)
- NetBeans / VS Code
- Maven (proyectos con pom.xml)
- JGraphT 1.5.1 (grafos)

## Cómo ejecutar

**Proyectos NetBeans (.xml):**
Abrir la carpeta del proyecto en NetBeans → Run

**Proyectos Maven:**
```bash
cd nombre-del-proyecto
mvn compile
mvn exec:java -Dexec.mainClass="com.mycompany.paquete.Main"
```

**Proyectos VS Code (.vscode):**
Abrir en VS Code con extensión Java → Run desde Main.java
